# 参加プログラムの作成手順

## この文書について

この文書では、Super Dungeon Wars Programming Battleに参加するために、
Unityプロジェクトを開き、自分のパーティーを作成してテストするまでの流れを説明します。

提出方法は、[提出方法](SubmissionGuide.md)を確認してください。

## 必要なもの

参加には、以下が必要です。

- Windows PC
- Unity Hub
- Unity 6000.3.24f1
- GitHubから取得した本リポジトリ
- Connpassアカウント

Unityは、必ず次のバージョンを使用してください。

```text
Unity 6000.3.24f1
```

異なるUnityバージョンでプロジェクトを開くと、
Package、Prefab、ProjectSettingsなどに意図しない変更が発生する場合があります。

## リポジトリを取得する

GitHubから本リポジトリを取得します。

Gitを使用できる方は、Cloneによる取得をおすすめします。
今後の更新を取り込みやすくなるためです。

Gitを使用しない場合は、GitHubの `Code` メニューから
ZIP形式でダウンロードし、任意の場所へ展開してください。

## Unityプロジェクトを開く

Unity Hubを起動します。

`Add` または `Open` を選択し、リポジトリ内の次のフォルダを指定してください。

```text
SuperDungeonWars-ProgrammingBattle/SuperDungeonWars
```

リポジトリのルートフォルダではなく、
`SuperDungeonWars` フォルダをUnityプロジェクトとして開いてください。

初回起動時には、Unityが必要なPackageやLibraryを作成するため、
プロジェクトが開くまでに時間がかかる場合があります。

## Connpass IDを設定する

Unity Editor内の参加者設定画面で、Connpass IDを入力します。

Connpass IDは、提出されたパーティーと応募者を対応付けるために使用します。

設定時は、次の点に注意してください。

- Connpassのパスワードは入力しないでください。
- Connpass上で使用しているIDを正確に入力してください。
- 表示名とログイン用IDが異なる場合は、募集案内で指定されたIDを使用してください。
- チーム参加時の設定方法は、募集開始時に案内します。

参加者設定画面の場所および具体的な入力方法は、
参加者向け機能の完成後にスクリーンショット付きで案内します。

## 参加者用パーティーPrefabを作成する

Unity Editor内の参加者向け作成機能を使用して、
自分のパーティー用Prefabを作成します。

作成されたPrefabには、参加者が編集するための設定とスクリプトが含まれます。

以後は、原則として作成された参加者用Prefabと、
そのPrefabが参照する参加者用スクリプトを編集してください。

ゲームシステム側のPrefab、Scene、スクリプトを直接変更すると、
提出時にエラーとなる場合があります。

参加者用Prefabを作成した後は、次の順番で作業します。

1. Connpass IDを確認します。
2. パーティーの編成を設定します。
3. パーティーの行動方針を実装します。
4. 必要に応じて外見を設定します。
5. テストシーンで動作を確認します。
6. 提出用データを作成します。

作成機能の場所、Prefabの保存先、出力されるファイル名は、
募集開始時に案内します。

## パーティーを編成する

参加者は、用意された職業、装備、スキルなどを組み合わせ、
4人の冒険者からなるパーティーを作成します。

編成にはコスト制限があります。

探索、戦闘、財宝運搬、護衛など、
何を重視するかを考えて編成してください。

編成可能な要素、各要素の性能、コストは、
Unity Editor上で確認できるようにする予定です。

ゲームの基本的なルールは、[ゲームルール](GameRules.md)を確認してください。

## 行動方針を実装する

作成された参加者用スクリプトを編集し、
パーティーの行動方針を実装します。

たとえば、次のような処理を実装します。

- 次に探索する場所を決める。
- 発見した財宝を回収するか判断する。
- 敵やモンスターを見つけたときの対応を決める。
- 財宝を持つ仲間を護衛する。
- 危険度や残り時間に応じて帰還する。
- 既知マップから安全な経路を探す。

利用できる関数、データ、イベントについては、
[関数リファレンス](APIReference.md)を確認してください。

## 外見を設定する

参加者用Prefabでは、運営が許可した範囲で
アクセサリーなどの外見要素を設定できます。

外見の設定は、観戦時に自分のパーティーを識別しやすくするための要素です。

ただし、外見用オブジェクトに次のコンポーネントを追加することは禁止します。

- Collider
- Rigidbody
- Joint
- ゲーム進行に影響するスクリプト
- 大きな処理負荷を発生させるコンポーネント

使用可能な素材、サイズ、数などの詳細は、
募集開始時に案内します。

## テストする

提出前に、必ずUnity Editor上でテストしてください。

少なくとも、次の項目を確認してください。

- Unity Consoleにコンパイルエラーが出ていない。
- 参加者用Prefabが正しく作成されている。
- パーティーがゲーム開始後に行動する。
- 行動プログラムで例外が発生していない。
- パーティー編成がコスト制限を超えていない。
- Connpass IDが設定されている。
- 禁止されたコンポーネントを追加していない。

## 提出する

提出方法は、[提出方法](SubmissionGuide.md)を確認してください。

提出の受付開始前には、提出先へデータを送らないでください。
