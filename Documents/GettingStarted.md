# はじめに

このページでは、スーパーダンジョンウォーズのUnityプロジェクトをダウンロードし、サンプル対戦を確認してから、自分のパーティーを作成・編集・対戦へ参加させるまでの手順を説明します。

## 必要な環境

開発にはUnity Hubと、次のバージョンのUnity Editorを使用します。

```text
Unity 6000.3.24f1
```

Unity Hubから、このバージョンのUnity Editorをインストールしてください。

参加者はUnityとC#を使って、パーティーの行動をプログラムします。プログラミングにおけるAIツールの使用に制限はありません。

## プロジェクトをダウンロードして開く

### ZIPをダウンロードする

[GitHubのリポジトリ](https://github.com/SXG-xeen-Kagawa/SuperDungeonWars-ProgrammingBattle) を開き、`Code → Download ZIP` を選択してください。

ダウンロードしたZIPファイルは、任意の作業フォルダへ解凍してください。ZIPファイル内から直接プロジェクトを開かないでください。

この方法では、Gitのインストールや操作は不要です。

### Unity Hubへ登録する

Unity Hubのプロジェクト画面から、既存のプロジェクトを追加する操作を選びます。

解凍したフォルダの中にある、次のフォルダを指定してください。

```text
SuperDungeonWars
```

> [!IMPORTANT]
> Unity Hubへ登録するのは、解凍したリポジトリの最上位フォルダではなく、その中にある `SuperDungeonWars` フォルダです。
>
> 選択したフォルダの中に、`Assets`、`Packages`、`ProjectSettings` があることを確認してください。

登録したプロジェクトを、Unity `6000.3.24f1` で開いてください。

初回はアセットの読み込みなどに時間がかかることがあります。処理が完了してから、次の操作へ進んでください。

## まずサンプル対戦を確認する

最初に、あらかじめ用意されている4チームの対戦を確認してください。

Unity Editorで、次のシーンを開きます。

```text
Assets/Dungeon/Scenes/MazeExplore
```

シーンを開いたら、Unity Editor上部の再生ボタンを押してPlay Modeを開始してください。

サンプルの4チームによる対戦が始まります。

迷路の探索、宝箱の回収、宝箱を運ぶキャラクターの護衛、ほかのチームへの攻撃などを見て、ゲームの流れを確認してください。

ゲームの基本ルールは、[ゲームルール](GameRules.md) を参照してください。

対戦を確認したら、再生ボタンをもう一度押してPlay Modeを終了し、自分のパーティーの作成へ進みます。

## 自分のパーティーを作成する

### Connpassでエントリーする

大会へ参加するには、[connpassの募集ページ](https://connpass.com/event/407970/) からエントリーし、connpass受付番号を取得してください。

挑戦者作成時には、connpassで発行された受付番号を入力します。

開催日、提出締切などの大会に関する情報は、募集ページで確認してください。

### 挑戦者作成画面を開く

Unity Editorのメニューバーから、次の項目を選択します。

```text
プロバト → 挑戦者作成
```

挑戦者作成画面が開きます。

![挑戦者作成画面](Images/GettingStarted_CreateChallenger.png)

### パーティー情報を入力する

挑戦者作成画面では、以下の情報を設定します。

| 項目 | 内容 |
| --- | --- |
| Connpass受付番号 | connpassでエントリーした際に発行される受付番号です。 |
| 作成者名 | 配信や結果表示などで使用する作成者名です。 |
| パーティー名 | 作成するパーティーの名前です。 |
| チームの簡単な説明 | パーティーの戦略や特徴を紹介する短い説明です。 |
| チームアイコン | 配信や観戦画面などで使用するチームアイコンです。 |

必要事項を入力したら、`作成` ボタンを押してください。

connpass受付番号以外の項目は、作成後も変更できます。最初は仮の内容で作成してから、後で調整しても構いません。

作成に成功すると、参加者用フォルダ、Partyスクリプト、Characterスクリプト、パーティーPrefab、キャラクターPrefabが作成されます。

## パーティーPrefabを編集する

挑戦者の作成後、パーティーPrefabの編集画面が開きます。

Prefabは、ゲーム内で使用するオブジェクトの構成や設定を保存したアセットです。

![パーティーPrefabの編集画面](Images/GettingStarted_PartyPrefab.png)

パーティーPrefabでは、主にパーティー全体に関する情報とAIを編集します。

### Inspectorで設定できる情報

Inspectorでは、次の情報を変更できます。

| 項目 | 内容 |
| --- | --- |
| 制作者名 | 配信や結果表示などで使用する作成者名です。 |
| 所属（学校・団体名） | 制作者の所属です。任意で入力できます。 |
| パーティー名 | 作成するパーティーの名前です。 |
| パーティーの紹介 | パーティーの戦略や特徴を紹介する短い説明です。 |
| パーティーアイコン | 配信や観戦画面などで使用するアイコンです。 |

パーティーアイコンには、`Assets/Dungeon/GameAssets/Icons/` に用意されたサンプル画像を割り当てられます。

自分で用意した画像を使用する場合は、その画像を自分の参加者用フォルダ内に配置してから、パーティーアイコンに設定してください。フォルダ外の自作画像を参照したまま提出することはできません。

設定を変更したら、Prefab Mode上部の **Save** を押して保存してください。

### 編集画面のメニュー

パーティーPrefabの編集画面には、次のボタンがあります。

| ボタン | 内容 |
| --- | --- |
| `Partyスクリプトを開く` | パーティー全体の行動を決めるAIスクリプトを開きます。 |
| `Character Prefabを開く` | キャラクターPrefabの編集画面を開きます。 |
| `提出用ZIPを作成...` | 提出用のZIPファイルを作成します。 |

## キャラクターPrefabを編集する

`Character Prefabを開く` を押すと、キャラクターPrefabの編集画面が開きます。

![キャラクターPrefabの編集画面](Images/GettingStarted_CharacterPrefab.png)

キャラクターPrefabでは、Characterスクリプトの編集と、見た目のアクセサリ追加を行えます。

### キャラクターAIを編集する

`Characterスクリプトを開く` を押すと、各キャラクターの行動を決めるAIスクリプトを開けます。
