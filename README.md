# Super Dungeon Wars Programming Battle

Super Dungeon Warsは、4人の冒険者で構成されたパーティーをプログラムし、
ダンジョンの探索、戦闘、財宝の回収を競う対戦型プログラミングバトルです。

参加者は、Unity上で自分のパーティーを作成します。
そして、未知のダンジョンをどのように探索するか、敵やモンスターとどう戦うか、
財宝をいつ回収して持ち帰るかといった行動方針をプログラムします。

本作は、参加者が自分で考えて作る楽しさと、
作られたパーティー同士の対戦を観戦する楽しさの両方を目指した、
イベント向けのプログラミングバトルです。

> このリポジトリは、SXG2026でのSuper Dungeon Wars Programming Battle開催に向けた開発・参加者募集用プロジェクトです。  
> ゲームルール、参加方法、API、提出方法などは、開発状況に応じて更新されます。

## SXG2026について

SXG2026では、Super Dungeon Warsのプログラミングバトルを実施予定です。

大会では、参加者が作成したパーティーによる予選を行い、
予選を通過したパーティーによるトーナメントを予定しています。

募集期間、提出期限、参加条件、大会形式の詳細は、
募集開始時にこのリポジトリおよびイベント告知で案内します。

## Unityプロジェクトを開く

Unity Hubから、リポジトリ内の次のフォルダを指定して開いてください。

```text
SuperDungeonWars
```

### 対応Unityバージョン

```text
Unity 6000.3.24f1
```

原則として、上記と同じUnityバージョンを使用してください。

異なるバージョンでプロジェクトを開くと、Package、Prefab、ProjectSettingsなどに
意図しない変更が加わる場合があります。

## 開発状況について

このプロジェクトは開発中です。

参加者が作成するパーティーPrefab、パーティー編成、行動プログラム、
既知マップ、財宝、戦闘、提出機能などを整備しています。

公開済みの仕様は変更される場合がありますが、
参加者が作成したプログラムをできる限り継続利用できるよう配慮します。

大きな仕様変更を行う場合は、このリポジトリ内で案内します。
