# Super Dungeon Wars Programming Battle

</p>

自分でプログラムした冒険者パーティーをダンジョンへ送り込み、財宝の持ち帰りを競うプログラミングバトルです。

参加者はパーティーの編成と行動を設計し、探索、宝箱の回収、ほかのパーティーとの駆け引きを行います。自分で考えて作ったパーティーがダンジョンでどのように動き、どのような結果を出すのかを楽しめます。

> [!NOTE]
> 本リポジトリは開発中です。ゲーム仕様、参加方法、API、提出方法などは、開発状況に応じて更新されます。

## 概要

Super Dungeon Wars Programming Battle は、4つの冒険者パーティーが同じ迷宮を探索し、宝箱を持ち帰って獲得コイン数を競うゲームです。

迷宮の中央には、必ず金の宝箱が配置されます。金の宝箱には、一般の宝箱よりも多くのコインが入っています。

迷宮内には一般の宝箱も配置されます。宝箱を見つけたら、自分たちの入口だけでなく、4チームのいずれかの入口まで持ち帰ることでコインを獲得できます。

制限時間終了時に、持ち帰った宝箱に入っていたコインの合計が最も多いチームの勝利です。

## ゲームの特徴

- 4チームが、それぞれ異なる入口から同じ迷宮へ進入します。
- 迷宮の中央の部屋は固定位置にあり、必ず金の宝箱が配置されます。
- 金の宝箱には、一般の宝箱よりも多くのコインが入っています。
- 一般の宝箱は迷宮内に配置されます。
- 宝箱は4チームのいずれかの入口へ持ち帰ることができます。
- 試合ごとに迷路の構造が変化します。
- モンスターは出現しません。
- ほかのパーティーとの遭遇や戦闘を含め、探索方針と状況判断が勝敗に影響します。
- パーティーの編成、役割分担、探索順序、宝箱の運搬、撤退判断などに戦略の違いが表れます。

## 参加者が作るもの

参加者は、ゲーム内で動作する冒険者パーティーを作成します。

主に、次のような要素を組み合わせて、自分だけの戦略を実装します。

- パーティーの編成
- 各キャラクターの役割分担
- 迷宮の探索方針
- 宝箱を発見した際の行動
- 金の宝箱を狙うか、一般の宝箱を集めるかという判断
- ほかのパーティーと遭遇した際の対応
- 宝箱をどの入口へ持ち帰るかという判断

細かな移動操作そのものではなく、「どこへ向かうか」「何を優先するか」という判断をプログラムで組み立てることを重視しています。

## 勝敗の決まり方

試合終了時に、各チームが持ち帰った宝箱のコイン数を合計します。

最も多くのコインを持ち帰ったチームが勝利します。

中央の金の宝箱は高い価値を持つため、多くのチームが狙う重要な目標になります。一方で、一般の宝箱を効率よく集める戦略や、ほかのチームの動きを見て行動を変える戦略も考えられます。

詳しいルールは、[ゲームルール](Documents/GameRules.md) を参照してください。
