# Super Dungeon Wars Programming Battle

Super Dungeon Warsは、冒険者パーティーをプログラムしてダンジョンを攻略する、
対戦型プログラミングバトルです。

参加者は、パーティーの編成や行動方針を作成します。
探索、戦闘、財宝の確保、撤退判断などの工夫によって、
他のパーティーと競い合います。

> このリポジトリは現在開発中です。
> SXG2026での参加者募集に向けて、順次内容を整備・公開します。

## ゲーム概要

4つのパーティーが、それぞれ異なる入口からダンジョンへ入場します。

ダンジョン中央にある財宝を確保し、自分たちの出口まで持ち帰ることが主な目的です。
道中ではモンスターや他パーティーとの戦闘が発生します。

制限時間終了時には、持ち帰った財宝を中心に、
探索・戦闘・生存などの成果を評価して勝敗を決定します。

## 参加者が作るもの

参加者は、ゲーム内で動く冒険者パーティーのプログラムを作成します。

パーティーには職業・装備・スキルなどの選択肢があり、
コスト制限の中で編成を考えます。

たとえば、次のような方針を工夫できます。

- 未知のエリアを効率よく探索する。
- 財宝を優先して中央を目指す。
- 敵パーティーとの戦闘を避け、安全に帰還する。
- 強いパーティーを編成して、中央で財宝を奪い合う。
- 状況に応じて、探索・戦闘・撤退の判断を切り替える。

## 特徴

本作では、参加者が細かなキャラクター移動を操作するのではなく、
「次にどこへ向かうか」「何を優先するか」という探索・攻略方針を
プログラムで設計することを重視しています。

各パーティーには、自分たちが視界によって把握したダンジョン情報が提供されます。
未知の領域を探索しながら、既知の地図を利用して行動を組み立てます。

## 開発環境

- Unity：準備中
- プログラミング言語：C#
- 対象プラットフォーム：Windows

Unityのバージョン、導入手順、参加者向けAPIなどは、準備でき次第公開します。
